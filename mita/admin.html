Routing policies

awgm-box routes all traffic: each policy sends its domains, networks and GeoSite / GeoIP categories to one saved outbound, directly, or blocks them. Policies are checked top to bottom; the first match wins. Saving applies instantly, without restarting Mita.

Geo sources

Where geosite: and geoip: categories come from. Leave a field empty to use MetaCubeX categories; set a v2ray .dat link to read categories from it instead, for example Runet Freedom's geosite:ru-blocked.

Links must point to GitHub (including release downloads) or jsDelivr. Files are downloaded on save, cached, and refreshed daily together with the categories. Category names are those inside the file, e.g. geosite:ru-blocked, geoip:ru-blocked; geosite:google@cn keeps only entries with that attribute.
